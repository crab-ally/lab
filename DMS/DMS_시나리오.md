# DMS (Driver Monitoring System) 시나리오

---

## 1. 개요 (Overview)

### 1.1 목적
운전자의 얼굴(고개 방향) 및 눈 상태를 실시간으로 모니터링하여 **전방주시태만** 및 **졸음운전**을 감지하고, 위험도에 따라 단계적으로 경고를 제공하여 사고를 예방한다.

### 1.2 시스템 구성 (H/W)

| 구성요소 | 설명 |
|---|---|
| IR LED | 850~940nm 대역, 야간/역광/터널 등 조도 저하 환경에서도 얼굴 조도 확보 |
| IR 카메라 | IR LED 반사광 수광, 가시광 대비 눈부심·조도 영향 최소화 |
| 차량 속도 신호 | CAN(또는 Vehicle Bus)에서 차속 신호 수신 |
| DMS ECU/SoC | 얼굴 검출, 랜드마크 추출, Head Pose 추정, 눈 개폐(EAR/PERCLOS) 판단 로직 수행 |
| HMI(스피커/클러스터/HUD) | 안내음, 경고음, TTS 멘트 출력 |

### 1.3 인식 대상
- 운전자 얼굴 검출 (Face Detection)
- 얼굴 랜드마크 기반 Head Pose(Yaw/Pitch/Roll) 산출
- 눈 영역 검출 및 개폐 상태 판단 (동공/눈꺼풀 기반)

---

## 2. 동작 조건 (Precondition)

DMS 기능은 아래 조건을 **모두 만족**할 때만 활성화된다.

| 조건 | 상세 |
|---|---|
| 시동 상태 | IGN ON (ACC 단독 상태 제외) |
| 주행 상태 | 차속 > 임계값(예: 3 km/h) 이상 |
| 정차 제외 | 시동 ON + 차속 0 km/h(정지) 상태는 **DMS 비활성** |
| 카메라 상태 | 얼굴 인식 가능 (렌즈 가림, 오검출 아님) |

> **비고**: 차속 0km/h 판정 시 채터링 방지를 위해 저역통과 또는 디바운스(예: 0.5초) 적용 권장. 정지→출발 전환 시 활성화, 출발→정지 전환 시 즉시(또는 수백 ms 디바운스 후) 비활성화 및 알람 초기화.

**상태 전이**

```
[IGN OFF] --IGN ON--> [대기(정차)] --차속>3km/h--> [DMS 활성(모니터링)]
[DMS 활성] --차속=0 (디바운스)--> [대기(정차)] --IGN OFF--> [IGN OFF]
```

## 3. 시나리오 상세

### 3.1 시나리오 1: 전방주시태만 & 졸음운전 (Head Pose 기반)

**감지 로직**: 얼굴 Yaw/Pitch 각도가 기준각 이상으로 벗어난 상태가 일정시간 지속되면 단계적 경고

| 단계 | 판단조건(예시값, 튜닝대상) | 지속시간(예시) | 알람 |
|---|---|---|---|
| 정상 | \|Yaw\| < 25° AND \|Pitch\| < 15° | - | 없음 |
| 1단계(주의) | \|Yaw\| ≥ 25° 또는 \|Pitch\| ≥ 15° | 2.0초 지속 | 안내음(Chime, 1회) |
| 2단계(경고) | 1단계 상태에서 추가 지속 | 누적 4.0초 지속(또는 1단계 후 +2초) | 경고음(반복 Beep) + 클러스터 경고 아이콘 |
| 해제 | 정상 각도 범위로 복귀 | 0.5초 이상 유지(디바운스) | 알람 해제, 타이머 리셋 |

**시퀀스**
```
정상 주시
  └(각도 이탈 감지)→ 이탈 타이머 시작
       ├ 2.0초 유지 → [안내음 출력]
       │      └ 추가 2.0초(누적4.0초) 유지 → [경고음 출력 + 추가멘트 로직 트리거]
       └ 도중 정상 복귀(0.5초 이상) → 타이머 리셋, 알람 OFF
```

---

### 3.2 시나리오 2: 졸음운전 (눈 감김 기반)

**감지 로직**: 고개는 정면(정상 각도 범위)이나, 눈 감김 상태(EAR 임계값 이하 또는 PERCLOS 기준)가 지속되면 졸음으로 판단

| 단계 | 판단조건(예시값) | 지속시간(예시) | 알람 |
|---|---|---|---|
| 정상 | 눈뜸 상태 | - | 없음 |
| 1단계(주의) | 눈감김(Eye Closed) 지속 | 1.5초 지속 | 안내음 |
| 2단계(경고) | 눈감김 지속 | 누적 3.0초 지속 | 경고음 + 클러스터 경고 |
| 해제 | 눈뜸 복귀 | 즉시~0.3초 디바운스 | 알람 해제, 타이머 리셋 |

> **비고**: 단순 깜빡임(Blink, 통상 0.1~0.4초)과 졸음성 눈감김을 구분하기 위해 최소 판단시간(예: 1.5초)을 두어 오검출 방지. PERCLOS(단위시간 내 눈감김 비율) 방식을 병행 적용 시 더 정교한 판단 가능.

**시퀀스**
```
정면 주시 + 눈뜸
  └(눈감김 감지)→ 눈감김 타이머 시작
       ├ 1.5초 유지 → [안내음 출력]
       │      └ 추가 1.5초(누적3.0초) 유지 → [경고음 출력 + 추가멘트 로직 트리거]
       └ 도중 눈뜸 복귀 → 타이머 리셋, 알람 OFF
```

---

### 3.3 시나리오 우선순위 및 동시 발생 처리

| 상황 | 처리 |
|---|---|
| 고개 이탈 + 눈감김 동시 발생 | 두 로직 병렬 판단하되, 알람 단계가 더 높은(경고>안내) 쪽 우선 출력. 스피커 알람 중복 출력 방지(동시 발화 X) |
| 시나리오1 경고 중 시나리오2 발생 | 기존 경고 유지, 로그상 복합상황(전방주시태만+졸음)으로 기록 |

## 4. 제한사항: 선글라스 착용 시 처리

| 상황 | 판단 방식 |
|---|---|
| IR 투과형 선글라스 (동공 인식 가능) | 기존 로직과 동일하게 Head Pose + 눈감김 판단 모두 수행 |
| IR 비투과 선글라스 (동공 인식 불가) | **눈감김 판단 로직 비활성화**, Head Pose(고개 각도) 로직만으로 시나리오1·2 통합 판단 |

**Fallback 로직 (동공 인식 불가 시)**

```
얼굴 검출 O, 눈 랜드마크/동공 검출 실패(N프레임 연속)
  → "선글라스/눈 미검출 모드" 진입
  → 시나리오2(눈감김 기반 졸음판단) 비활성
  → 시나리오1(Head Pose) 임계값을 졸음 대응 목적상 소폭 보수적으로 조정 검토
     (예: Pitch 하방 이탈 - 졸 때 고개가 아래로 떨어지는 패턴 - 임계각 완화 또는 지속시간 단축 고려)
  → 동공 재검출 시 자동으로 일반 모드 복귀
```

> **비고**: 동공 인식 실패가 일시적 각도 이탈(고개 돌림)로 인한 것인지, 실제 선글라스로 인한 지속적 미검출인지 구분 필요. 예: 일정 프레임(N) 이상 연속 미검출 시에만 "선글라스 모드"로 판정하여 일반 고개 돌림 상황과 오판 방지.

## 5. 추가 기능: 경고음 발생 시 추가 안내 멘트 (TTS)

**트리거**: 시나리오1 또는 시나리오2가 **2단계(경고)** 에 진입한 시점

| 조건 | 안내 멘트 |
|---|---|
| 현재 주행 도로 = 고속도로(내비/ADAS Map 정보 기준) AND 전방 N km 이내 휴게소 존재 | "전방 N km에 휴게소가 있습니다" |
| 고속도로이나 인근 휴게소 정보 없음 | 경고음만 출력 (멘트 없음) 또는 "졸음운전이 감지되었습니다. 휴식이 필요합니다" 등 일반 멘트 |
| 일반도로/시내 | 경고음만 출력, 별도 휴게소 멘트 없음 |

**필요 연동 정보**
- 내비게이션/ADAS Map으로부터 현재 도로 속성(고속도로 여부) 수신
- 내비게이션 POI 데이터로부터 전방 휴게소까지의 거리(N km) 조회

**시퀀스**
```
[경고음 트리거]
  → 도로타입 조회(고속도로 여부)
       ├ 고속도로 O → 전방 휴게소 검색
       │      ├ 존재 → TTS "전방 N km에 휴게소가 있습니다" 재생
       │      └ 미존재 → 경고음만 유지
       └ 고속도로 X → 경고음만 유지
```

## 6. 전체 상태 전이도 (요약)

```
IGN OFF
  │ IGN ON
  ▼
대기(정차, DMS 비활성)
  │ 차속 > 3km/h
  ▼
DMS 모니터링(정상)
  │
  ├─[Yaw/Pitch 이탈 지속]──▶ 주시태만 안내음 ──[추가지속]──▶ 주시태만 경고음 ──▶ (고속도로 시 TTS 멘트)
  │        │복귀                                   │복귀
  │        ▼                                        ▼
  │     정상                                       정상
  │
  ├─[정면+눈감김 지속]──▶ 졸음 안내음 ──[추가지속]──▶ 졸음 경고음 ──▶ (고속도로 시 TTS 멘트)
  │        │복귀                              │복귀
  │        ▼                                   ▼
  │     정상                                  정상
  │
  └─[차속=0 디바운스]──▶ 대기(정차) ──[IGN OFF]──▶ IGN OFF
```

## 7. 예외/오검출 처리 (Fail-safe)

| 예외상황 | 처리방안 |
|---|---|
| 얼굴 미검출(N프레임 연속) | DMS 판단 보류, 별도 "운전자 얼굴 미인식" 상태 플래그(과도한 알람 방지), 일정시간 지속 시 클러스터에 안내(선택) |
| 다중 얼굴 검출(동승자 등) | 운전석 위치 기준 ROI 내 얼굴만 판단 대상으로 필터링 |
| IR LED/카메라 고장 | DMS Fail 상태 진입, 경고등(고장) 표시, 기능 비활성화 |
| 강한 역광/직사광 | IR 필터 특성상 영향 최소화되나, 검출 실패율 급증 시 미검출 로직과 동일 처리 |
| 급격한 각도 변화(순간적 확인 등, 예: 사이드미러 확인) | 최소 판단시간(2.0초/1.5초) 자체가 순간 동작 필터 역할 수행 |

---

## 8. 미확정 항목 (실차 검증 필요)

- Head Pose 임계각(Yaw/Pitch) 및 지속시간(2.0초/4.0초) — 법규(예: Euro NCAP DMS 가이드라인 등) 및 실차 튜닝 기반 확정 필요
- 눈감김 판단 임계시간(1.5초/3.0초) — Blink 오검출 방지 위한 최소값 실차 검증 필요
- 정차 판정 디바운스 시간
- 선글라스 모드 진입 판정 프레임 수(N)
- 안내음/경고음 사운드 소스 및 반복 주기 스펙
- 도로타입/휴게소 정보 연동 인터페이스(내비게이션 시스템과의 API/신호 정의)
