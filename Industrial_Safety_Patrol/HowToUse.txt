# ==================== MuJoCo 시뮬레이터 실행 ====================
1. [터미널1] docker compose up -d
1-1. docker compose exec robot_sim bash
1-2. python3 scripts/mujoco_ros2_bridge.py

# 로봇 수동 조종 (Teleop) - 키보드로 직접 이동
2. [터미널2] docker compose run --rm teleop
2-1. 터미널 창에 포커스를 둔 상태에서 안내된 키(i, j, k, l, , 등)를 눌러 로봇을 조종합니다.

# SLAM Toolbox 실행
3. [터미널3] docker compose --profile slam up -d slam
3-1. docker exec -it safety_patrol_slam bash
3-2. ros2 node list → /slam_toolbox 확인
3-3. ros2 topic list → /scan, /odom, /tf, /map, /map_metadata 확인
3-4. ros2 launch slam_toolbox online_async_launch.py \
slam_params_file:=/workspace/config/slam_toolbox_factory.yaml

# 실시간 SLAM 매핑 시각화 (RViz)
3-5. [터미널4] docker compose --profile slam up rviz_slam
3-6. RViz 창이 열리면 좌측 하단 'Add' 버튼을 클릭합니다.
3-7. 'By topic' 탭에서 /map (Map)과 /scan (LaserScan)을 추가합니다.
3-8. 좌측 상단 Global Options의 'Fixed Frame'을 'map'으로 설정하면 실시간 매핑 과정을 볼 수 있습니다.

# 봇 자동 탐색 주행 실행
4. [터미널5] docker compose run --rm auto_explore

# 완성된 지도 저장
5. [터미널6] docker compose run --rm map_saver
5-1. 파일(.yaml, .pgm) 생성

# ==================== Nav2 자율주행 실행 ====================
# (※ 시뮬레이터가 실행 중이어야 하며, 맵 파일이 존재해야 합니다.)
6. [터미널7] docker compose --profile nav2 up nav2 rviz
6-1. RViz2 창이 열리면 상단의 '2D Pose Estimate' 툴을 사용하여 로봇의 초기 위치를 지정합니다.
6-2. 'Nav2 Goal' 툴을 사용하여 목적지를 지정하면 봇이 경로를 탐색하여 자율주행합니다.

# 화재감지 실행
7. [터미널8] python scripts/fire_detection_node.py

# yolo + ppe + sensor fusion + ttc
1. cd ros2_ws
2. colcon build --packages-select perception_safety_pkg
3. source install/setup.bash
4. ros2 launch perception_safety_pkg safety_pipeline.launch.py
